## 三、时间紧时的「最小可行知识面」

只剩 1 个月时的取舍（按性价比排序，保住 80% 的面试得分点）：

1. 🔴 并发：线程池 + synchronized/volatile + ThreadLocal + ConcurrentHashMap（2 天）
2. 🔴 JVM：内存区域 + GC 基础 + 双亲委派 + 两条排查流程（2 天）
3. 🔴 MySQL：B+ 树/回表/覆盖 + 隔离级别/MVCC + 三大日志 + explain（3 天）
4. 🔴 Redis：五大类型 + 持久化 + 三兄弟 + 一致性 + 分布式锁（3 天）
5. 🔴 Spring：IoC/AOP + Bean 生命周期 + 事务失效 + 自动配置（2 天）
6. 🔴 场景题：秒杀设计 + 缓存一致性 + 消息不丢不重（2 天）
7. 🟡 MQ 三选一精通（RocketMQ 优先，含事务消息），另外两个会选型对比（2 天）
8. 🟡 算法：热题 100 的前 6 个专题 + 7 个手撕模板（贯穿每天）
9. 🟢 其余（网络细节、Nginx、MongoDB、SpringCloud 组件细节）只看本指南对应文件的「高频面试题」部分

## 四、与打卡和应用的联动

- 每章学完 → 应用「📝 选择填空练习」→「📖 章节小考」选本章 → 正确率 90%+ 才过
- 每个 🔴 文件 → STUDY-TRACKER 打卡全部勾完才算精通
- 周末 → 「🏁 综合大考」20 题，正确率 <85% 时用「🔁 只做错题」+ 首页「薄弱环节」定位补漏
- 本表每 2 周对照一次：已精通的降级为维持性复习，薄弱的升级投入
