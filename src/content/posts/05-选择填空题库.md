## 选择题

### 1.（Java基础·易）JDK、JRE、JVM 三者的包含关系是？
- A. JDK ⊃ JRE ⊃ JVM
- B. JVM ⊃ JRE ⊃ JDK
- C. JRE ⊃ JDK ⊃ JVM
- D. 三者互相独立

答案：A
解析：JDK = 开发工具 + JRE，JRE = JVM + 核心类库；只需运行程序装 JRE，要开发才装 JDK。详见[《01-环境搭建与基础语法》](/java-study-guide/posts/01-环境搭建与基础语法/)

### 2.（Java基础·中）`StringBuilder sb = new StringBuilder("a");` 调用 `change(sb)`，方法体为 `void change(StringBuilder x){ x.append("b"); x = new StringBuilder("c"); }`，之后 sb 的内容是？
- A. a
- B. ab
- C. c
- D. bc

答案：B
解析：Java 只有值传递：append 修改的是同一个对象，而重新赋值只改变了形参的指向，不影响实参。详见[《02-面向对象与核心类》](/java-study-guide/posts/02-面向对象与核心类/)

### 3.（Java基础·易）`Integer a = 127, b = 127; System.out.println(a == b);` 输出什么？
- A. true
- B. false
- C. 编译错误
- D. 不确定

答案：A
解析：IntegerCache 缓存 -128~127，范围内 == 比较的是同一个缓存对象；超出范围（如 128）必须用 equals。详见[《02-面向对象与核心类》](/java-study-guide/posts/02-面向对象与核心类/)

### 4.（Java基础·易）以下哪个不属于面向对象三大特性？
- A. 封装
- B. 继承
- C. 多态
- D. 重载

答案：D
解析：三大特性是封装、继承、多态；重载是编译期确定同签名不同参数的方法，不属于三大特性。详见[《02-面向对象与核心类》](/java-study-guide/posts/02-面向对象与核心类/)

### 5.（Java基础·易）try-with-resources 的主要作用是？
- A. 自动关闭实现了 AutoCloseable 的资源
- B. 自动提交事务
- C. 捕获所有异常
- D. 提升运行速度

答案：A
解析：编译器会生成 finally 中的关闭逻辑，避免资源泄漏，优于手写 try-catch-finally。详见[《04-异常-IO-反射-注解》](/java-study-guide/posts/04-异常-IO-反射-注解/)

### 6.（Java基础·中）关于 String 不可变，正确的解释是？
- A. String 是可变的，只是习惯上不改
- B. String 类被 final 修饰、内部数据私有且不暴露修改方法
- C. 频繁拼接字符串应优先用 String
- D. String 是基本数据类型

答案：B
解析：不可变带来安全性、字符串常量池复用、hashCode 可缓存；频繁拼接用 StringBuilder。详见[《02-面向对象与核心类》](/java-study-guide/posts/02-面向对象与核心类/)

### 7.（集合·中）JDK 1.8 中 ArrayList 首次 add 时容量扩到 10，此后每次扩容为原来的？
- A. 1.5 倍
- B. 2 倍
- C. 1.2 倍
- D. 3 倍

答案：A
解析：newCapacity = oldCapacity + (oldCapacity >> 1)，即 1.5 倍向下取整。详见[《03-集合与泛型》](/java-study-guide/posts/03-集合与泛型/)

### 8.（集合·中）HashMap（JDK 1.8）中链表转红黑树的条件是？
- A. 链表长度 ≥ 8 且数组长度 ≥ 64
- B. 链表长度 ≥ 8 即可
- C. 链表长度 ≥ 16
- D. 元素总数 ≥ 64

答案：A
解析：数组长度不足 64 时优先扩容而不是树化；红黑树退化回链表的阈值是 6。详见[《03-集合与泛型》](/java-study-guide/posts/03-集合与泛型/)

### 9.（集合·易）HashSet 判断元素是否重复依赖的方法是？
- A. 仅 equals
- B. 仅 ==
- C. hashCode 与 equals
- D. compareTo

答案：C
解析：先用 hashCode 定位桶，再在桶内用 equals 精确比较，两者必须一起重写。详见[《03-集合与泛型》](/java-study-guide/posts/03-集合与泛型/)

### 10.（集合·易）下列集合中线程安全的是？
- A. ArrayList
- B. HashMap
- C. Vector
- D. LinkedList

答案：C
解析：Vector 方法用 synchronized 修饰；现代并发场景更推荐 ConcurrentHashMap 或 CopyOnWriteArrayList。详见[《03-集合与泛型》](/java-study-guide/posts/03-集合与泛型/)

### 11.（集合·易）用 for-each 遍历 ArrayList 时直接调用 list.remove(o)，通常会？
- A. 正常删除
- B. 抛出 ConcurrentModificationException
- C. 编译错误
- D. 静默删除所有元素

答案：B
解析：fail-fast 机制检测到 modCount 被修改即抛异常；正确做法是 Iterator.remove() 或 removeIf。详见[《03-集合与泛型》](/java-study-guide/posts/03-集合与泛型/)

### 12.（并发·易）直接调用线程对象的 run() 而不是 start()，结果是？
- A. 创建新线程执行
- B. 在当前线程中作为普通方法执行
- C. 抛出异常
- D. 永久阻塞

答案：B
解析：只有 start() 会让 JVM 创建新线程并调用 run()；直接调 run() 与普通方法调用无异。详见[《01-多线程与并发编程》](/java-study-guide/posts/01-多线程与并发编程/)

### 13.（并发·易）volatile 能保证的是？
- A. 原子性
- B. 可见性与有序性
- C. 原子性与可见性
- D. 原子性、可见性、有序性都保证

答案：B
解析：volatile 保证可见性和禁止指令重排，但 i++ 这类复合操作仍需 synchronized 或原子类。详见[《01-多线程与并发编程》](/java-study-guide/posts/01-多线程与并发编程/)

### 14.（并发·中）线程池提交任务后的处理顺序是？
- A. 核心线程 → 阻塞队列 → 非核心线程 → 拒绝策略
- B. 直接创建线程直到最大线程数
- C. 先入队列再创建核心线程
- D. 顺序随机

答案：A
解析：先占满核心线程，队列满了才扩非核心线程，到 max 后触发拒绝策略——这也是 FixedThreadPool 无界队列堆积 OOM 的根源。详见[《01-多线程与并发编程》](/java-study-guide/posts/01-多线程与并发编程/)

### 15.（并发·中）synchronized 锁升级的正确顺序是？
- A. 偏向锁 → 轻量级锁 → 重量级锁
- B. 重量级锁 → 轻量级锁 → 偏向锁
- C. 轻量级锁 → 偏向锁 → 重量级锁
- D. 不存在锁升级

答案：A
解析：JVM 按竞争激烈程度逐步升级且不可逆，目的是减少无竞争场景的开销。详见[《01-多线程与并发编程》](/java-study-guide/posts/01-多线程与并发编程/)

### 16.（并发·中）ThreadLocal 可能内存泄漏的根本原因是？
- A. key 是强引用
- B. key 是弱引用但 value 是强引用，线程长期存活时 value 无法回收
- C. value 是弱引用
- D. 底层是 ArrayList

答案：B
解析：线程池中线程长期存活，ThreadLocalMap 的 value 无法自动回收，用完必须调用 remove()。详见[《01-多线程与并发编程》](/java-study-guide/posts/01-多线程与并发编程/)

### 17.（并发·易）以下哪个不是 ThreadPoolExecutor 的拒绝策略？
- A. AbortPolicy
- B. CallerRunsPolicy
- C. DiscardPolicy
- D. FairPolicy

答案：D
解析：四种拒绝策略是 AbortPolicy、CallerRunsPolicy、DiscardPolicy、DiscardOldestPolicy。详见[《01-多线程与并发编程》](/java-study-guide/posts/01-多线程与并发编程/)

### 18.（JVM·中）以下运行时区域中，规范规定不会抛出 OutOfMemoryError 的是？
- A. 堆
- B. 虚拟机栈
- C. 程序计数器
- D. 元空间

答案：C
解析：程序计数器是唯一没有规定任何 OOM 情况的区域；栈是 StackOverflowError，堆和元空间都会 OOM。详见[《02-JVM核心》](/java-study-guide/posts/02-JVM核心/)

### 19.（JVM·易）判断对象是否可回收，主流商用虚拟机采用？
- A. 引用计数法
- B. 可达性分析（从 GC Roots 出发）
- C. 随机回收
- D. 手动释放

答案：B
解析：可达性分析解决了引用计数法的循环引用问题；GC Roots 包括栈帧局部变量、静态变量、常量、JNI 引用等。详见[《02-JVM核心》](/java-study-guide/posts/02-JVM核心/)

### 20.（JVM·中）双亲委派机制的主要作用是？
- A. 加快类加载速度
- B. 避免核心类被篡改与类的重复加载
- C. 是节省内存的唯一手段
- D. 为了支持热更新

答案：B
解析：子加载器先委托父加载器，保证 String 等核心类始终由 Bootstrap 加载，安全且唯一。详见[《02-JVM核心》](/java-study-guide/posts/02-JVM核心/)

### 21.（JVM·中）关于 G1 收集器，下列说法正确的是？
- A. 将堆划分为多个 Region，可设定目标停顿时间
- B. 只能回收新生代
- C. 基于标记-清除，必然产生大量碎片
- D. 是 JDK 8 的默认收集器

答案：A
解析：G1 按 Region 管理、可预测停顿（-XX:MaxGCPauseMillis），整体标记-整理、Region 间复制，JDK 9+ 默认。详见[《02-JVM核心》](/java-study-guide/posts/02-JVM核心/)

### 22.（MySQL·易）InnoDB 的默认事务隔离级别是？

### 23.（MySQL·中）假设 name 列有索引，下列条件能走索引的是？

### 25.（MySQL·中）binlog（二进制日志）的主要用途是？

### 29.（Redis·易）解决缓存穿透的常用手段是？

### 30.（Redis·中）关于 RDB 持久化，正确的是？

### 33.（Redis·中）Cache Aside 模式推荐的更新顺序是？

### 35.（消息队列·中）关于 Kafka 的消息顺序，正确的是？

### 37.（消息队列·中）RocketMQ 事务消息的正确流程是？
- A. 先投递消息再执行本地事务，失败无法处理

### 39.（框架·中）同类中方法 A 直接调用带 @Transactional 的方法 B，事务失效的原因是？

解析：TCP 全双工，两个方向各需一次 FIN 和一次 ACK。详见[《03-IO模型与网络编程》](/java-study-guide/posts/03-IO模型与网络编程/)

### 23.（Nginx·中）Nginx 把动态请求转交给后端应用的核心指令是＿＿＿。
答案：proxy_pass
解析：写在 location 块中；静态资源用 root/alias，动静分离即由此组合实现。详见[《07-Nginx》](/java-study-guide/posts/07-Nginx/)

### 24.（框架·中）Spring Cloud Gateway 中，定义"哪些请求转发到哪个服务"的配置叫＿＿＿规则。
答案：路由／Route
解析：路由 = 断言（Predicate，匹配条件）+ 过滤器（Filter，处理逻辑），是网关的核心抽象。详见[《SpringCloud微服务》](/java-study-guide/posts/04-SpringCloud微服务/)

### 25.（Elasticsearch·中）MySQL 与 ES 近实时同步，常用阿里开源的＿＿＿监听 binlog 异步写入 ES。
答案：canal
解析：canal 伪装成 MySQL 从库解析 binlog；其他方案还有同步双写与 MQ 异步，各有取舍。详见[《05-Elasticsearch》](/java-study-guide/posts/05-Elasticsearch/)

### 26.（MongoDB·易）MongoDB 中对应关系型数据库"行"的概念叫＿＿＿。
答案：文档／document
解析：集合 collection ≈ 表；文档以 BSON（二进制 JSON）存储。详见[《08-MongoDB》](/java-study-guide/posts/08-MongoDB/)
