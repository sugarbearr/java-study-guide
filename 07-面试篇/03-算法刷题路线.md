# 03-算法刷题路线

> **阶段**：面试篇 ｜ **建议总量**：热题 100 + 剑指 Offer 为主，200 题以内 ｜ **节奏**：从进阶篇开始每天 2~3 题，面试前保持手感

### 一、刷题总原则

- **先专题后套卷**：按下面的专题顺序集中攻一类套路，形成肌肉记忆；面试前一个月再刷 Hot 100 混排，模拟真实考试；
- **每天 2~3 题、限时**：简单题 15 分钟、中等题 25 分钟、困难题 40 分钟；到时没思路就看题解，看懂后**合上题解默写**才算完成；
- **错题隔天重做**：建一个"重刷清单"，3 天后重做仍能独立写出才打勾；面试前只重刷清单里的题；
- **一题多解**：每题先写暴力解，再逐步优化，每个解法都说得出时间/空间复杂度——面试官就是要听你的优化过程；
- **总量控制**：200 题以内、质量优先；刷 500 遘题不如把 150 道经典题刷透；
- **与指南进度配合**：进阶篇开始同步刷数组与链表，03-面试篇期间完成主干专题，冲刺期每天 1 题保手感。

### 四、手撕代码模板 ⭐（背诵级，面试默写）

**模板 1：反转链表（LC206）**

```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;   // 先存后继
        curr.next = prev;            // 反转指向
        prev = curr;                 // 双指针前移
        curr = next;
    }
    return prev;                     // prev 即新头
}
```

**模板 2：二分查找（LC704，左闭右闭）**

```java
public int search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {                    // 区间合法才继续
        int mid = left + (right - left) / 2;   // 防溢出写法
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;   // 收缩左边界
        else right = mid - 1;
    }
    return -1;
}
```

**模板 3：快速排序**

```java
public void quickSort(int[] nums, int left, int right) {
    if (left >= right) return;
    int pivot = nums[left], i = left, j = right;
    while (i < j) {
        while (i < j && nums[j] >= pivot) j--;   // 右侧找小的
        while (i < j && nums[i] <= pivot) i++;   // 左侧找大的
        swap(nums, i, j);
    }
    swap(nums, left, i);                          // 基准归位
    quickSort(nums, left, i - 1);
    quickSort(nums, i + 1, right);
}
private void swap(int[] a, int i, int j) { int t = a[i]; a[i] = a[j]; a[j] = t; }
```

**模板 4：归并排序**

```java
public int[] mergeSort(int[] nums, int left, int right) {
    if (left == right) return new int[]{nums[left]};
    int mid = left + (right - left) / 2;
    int[] l = mergeSort(nums, left, mid), r = mergeSort(nums, mid + 1, right);
    int[] res = new int[l.length + r.length];
    int i = 0, j = 0, k = 0;
    while (i < l.length && j < r.length) res[k++] = l[i] <= r[j] ? l[i++] : r[j++];
    while (i < l.length) res[k++] = l[i++];
    while (j < r.length) res[k++] = r[j++];
    return res;
}
```

**模板 5：BFS 层序遍历（LC102，网格 BFS 同骨架）**

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();               // 固定本层节点数，实现"分层"
        List<Integer> level = new ArrayList<>(size);
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

**模板 6：DFS 全排列（LC46，一切回溯题的骨架）**

```java
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    dfs(nums, new boolean[nums.length], new ArrayList<>(), res);
    return res;
}
private void dfs(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) {
        res.add(new ArrayList<>(path));        // 必须拷贝快照
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        used[i] = true; path.add(nums[i]);     // 做选择
        dfs(nums, used, path, res);
        path.remove(path.size() - 1); used[i] = false;   // 撤销选择
    }
}
```

**模板 7：LRU 缓存（LC146）——先说 LinkedHashMap 思路版**

```java
class LRUCache extends LinkedHashMap<Integer, Integer> {
    private final int capacity;
    public LRUCache(int capacity) {
        super(capacity, 0.75f, true);          // true = 按访问顺序排序
        this.capacity = capacity;
    }
    public int get(int key) { return super.getOrDefault(key, -1); }
    @Override
    protected boolean removeEldestEntry(Map.Entry<Integer, Integer> eldest) {
        return size() > capacity;              // 超容量淘汰最久未访问
    }
}
```

**模板 7（进阶）：手写 HashMap + 双向链表版**

```java
class LRUCache {
    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(0, 0), tail = new Node(0, 0);  // 哨兵

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail; tail.prev = head;
    }
    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        moveToHead(node);                      // 刚访问的提到最前
        return node.value;
    }
    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) { node.value = value; moveToHead(node); return; }
        if (map.size() == capacity) {          // 淘汰链表尾部（最久未用）
            Node last = tail.prev;
            remove(last); map.remove(last.key);
        }
        Node fresh = new Node(key, value);
        map.put(key, fresh); addToHead(fresh);
    }
    private void addToHead(Node n) { n.next = head.next; n.prev = head; head.next.prev = n; head.next = n; }
    private void remove(Node n) { n.prev.next = n.next; n.next.prev = n.prev; }
    private void moveToHead(Node n) { remove(n); addToHead(n); }
    static class Node { int key, value; Node prev, next; Node(int k, int v) { key = k; value = v; } }
}
```

### 五、面试场景应对

**五步法（按顺序执行，全程开口讲）**：

1. **澄清题意**：数据规模多大、是否有序/有重复、边界情况（空、单元素、负数），复述题目与面试官确认；
2. **说思路**：先讲暴力解再讲优化方向，征求面试官同意后再动手，避免闷头写偏；
3. **报复杂度**：时间/空间复杂度各是多少、为什么，这是面试官判断你是否受过训练的关键；
4. **动手写**：变量命名规范、保持缩进，边写边讲；卡住就先写伪代码骨架再填实现；
5. **自测用例**：写完主动跑一遍空输入、单元素、重复值等用例，自己先抓 bug 比被抓强。

**平台注意事项**：

- **白板/纸面**：先写函数骨架再填细节，保持布局整洁，写完站在面试官角度"通读"一遍；
- **牛客 ACM 模式**：要自己处理输入输出，提前练 `Scanner`/`BufferedReader` 读多行数据的标准套路；
- **共享文档（无编译器）**：靠脑内编译，写完口头逐行过一遍用例，主动说"这里我检查一下越界"；
- **卡壳时**：绝不沉默——大声思考，从 n=1、n=2 的小例子找规律，面试官往往在等你的思考过程而不是答案。
