| ABAC | Attribute-Based Access Control | 基于属性/策略：部门、时间、IP 等条件组合判断，粒度更细更难配 | 同上 |
| HTTPS / ⭐HSTS | HTTP over TLS / Strict Transport Security | HSTS 响应头让浏览器强制走 HTTPS，防降级与首跳被劫持 | ../02-进阶篇/03-IO模型与网络编程.md |
| 脱敏 | Data Masking | 手机号/身份证存或展示时打码（`138****1234`）；日志里也禁止打全量敏感信息 | ../04-框架篇/05-单元测试与工程质量.md |
| 加盐 | Salting | 存密码时给每个用户加随机串再哈希（`BCrypt` 内置），防彩虹表撞库；⚠️密码不是"加密"是"单向哈希+盐" | ../07-面试篇/01-Java高频八股速查.md |

## 🧪 测试与质量

|---|---|---|---|
| UT / IT / E2E | Unit / Integration / End To End Test | 单元（单类、全 mock）/ 集成（多组件、真依赖）/ 端到端（业务闭环） | ../04-框架篇/05-单元测试与工程质量.md |
| ⭐TDD | Test-Driven Development | 红-绿-重构：先写失败测试，再写实现，再整理；适合规则清晰的逻辑，不适合探索性代码 | 同上 |

## 🔺 易混淆对照（新人最常混的 12 组）

| 名字很像 | 区别（一句话分清楚） | 章节 |
|---|---|---|
| ⭐ES（Elasticsearch）vs ES（Event Sourcing） | 前者是搜索/日志引擎（倒排索引，中间件篇）；后者是"只存事件流、状态靠回放"的架构风格（DDD/CQRS 语境）。**看上下文：说"查日志/索引"是引擎，说"命令/事件"是溯源** | ../05-中间件篇/05-Elasticsearch.md |
| ⭐JWT vs Session | Session 状态在**服务端**内存/Redis（可随时踢人，扩容要共享）；JWT 状态**自包含在令牌里**（服务端无状态好横向扩，但签发后收不回来，需短过期+黑名单） | ../07-面试篇/01-Java高频八股速查.md |
| ⭐Ehcache/Caffeine vs Redis | 前者是**进程内本地缓存**（一级，微秒级，不共享、随应用重启即失效）；后者是**独立中间件**（二级，集群共享、可持久化、有网络往返）；多级缓存 = 本地挡热点 + Redis 挡全量 | ../05-中间件篇/01-Redis.md |
| ⭐rebase vs merge | merge 生成合并提交、保留真实分叉历史；rebase 重放提交、历史线性但**改写 sha → 公共分支禁用** | ../02-进阶篇/04-开发工具链-Git-Maven-Linux.md |
| String vs StringBuilder | String 不可变（每次拼接产生新对象，走常量池复用），StringBuilder 可变字符数组（单线程频繁拼接）；多线程用 StringBuffer，⚠️for 循环里用 `+` 是每轮 new 一个 builder | ../01-入门篇/02-面向对象与核心类.md |
| char vs varchar（MySQL） | `char(n)` 定长、不足补空格、不超长不截断，适合 MD5/手机号/状态；`varchar(n)` 变长 + 1~2 字节长度前缀，n 是**字符数**不是字节数（utf8mb4 一字符最多 4 字节） | ../03-数据库篇/01-MySQL基础与SQL实战.md |
| RDB vs AOF（Redis） | RDB 是"某一时刻的全量快照"（小、快、丢得多）；AOF 是"写命令流水账"（全、慢、丢得少）；生产用混合持久化 | ../05-中间件篇/01-Redis.md |
| 主从 vs 哨兵 vs 集群（Redis） | 主从只解决读写分离与备份（主挂了要人工切）；哨兵加**自动故障转移**（不扩容）；Cluster 加**数据分片 + 高可用**（16384 slot） | ../05-中间件篇/01-Redis.md |
| IoC vs DI | IoC 是**思想/目标**（创建与使用的控制权交给容器）；DI 是**实现手段**（容器把依赖注入进来：构造器/setter/字段）；说"依赖倒置原则 DIP"是它们的 SOLID 版本 | ../04-框架篇/01-Spring核心.md |
| `@Controller` vs `@RestController` | `@RestController` = `@Controller` + `@ResponseBody`；前者返回值默认当**视图名**解析，后者直接序列化 JSON 写回 | ../04-框架篇/02-SpringBoot实战.md |
| 限流 vs 降级 vs 熔断 | 限流=进门时控制流量；降级=主动放弃非核心保住核心；熔断=发现下游烂了暂时不调（快速失败+自愈） | ../04-框架篇/04-SpringCloud微服务.md |
| 幂等 vs 去重 vs 缓存 | 幂等=重复请求不出错（唯一业务号+状态机）；去重=同一元素只处理一次（布隆/唯一索引）；缓存=少算几遍 | ../06-分布式与高并发篇/02-高并发系统设计.md |
